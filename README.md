# My Tax Client Portal — Beta prototype

White-label client portal for tax offices (sample brand: Bright Path Tax).

**Live demo:** https://jasonaguirre-bot.github.io/tax-business/

- **Client website** — landing page, sign-in with phone or email + one-time code, 2-minute "Get started" booking flow (help needed → income types + ZIP → online / in person / upload → calendar → matched preparer → confirm), English / Español.
- **Client portal** — personal info (taxpayer, spouse, up to 5 dependents), tax form uploads, IDs & proof, direct deposit (routing validation, masked account), 4-step return tracker, messages, appointments, referrals, IRS form links.
- **Back office / Agent workspace** — clients, client files, stage changes, filing results, reminders (3-day cooldown), appointments, reports with CSV export, agents, branding.

Beta notes: all data is demo data stored in the visitor's browser (localStorage); files are listed by name only; sign-in codes are shown on screen instead of being texted/emailed. Staff demo password: demo1234.
